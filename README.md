# Stock Trading Platform

## Project Description

The Stock Trading Platform is a Java-based console application that simulates basic stock trading operations. Users can view available stocks, buy and sell shares, manage their portfolio, view transaction history, and monitor their account summary.

## Features

- View available market stocks
- Buy stocks
- Sell stocks
- View investment portfolio
- Track transaction history
- View account summary
- Calculate available cash balance
- Calculate portfolio value
- Calculate profit or loss
- Menu-driven console interface

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- ArrayList
- Scanner
- Visual Studio Code

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Compile the Java program:

```bash
javac StockTradingPlatform.java
